# AI/ML Lab Experiments

This repository contains my Artificial Intelligence and Machine Learning (AI/ML) lab experiments completed as part of my coursework.

## Repository Structure

Each experiment is organised in a separate folder and may include:

* Source code
* Jupyter/Colab notebooks
* Dataset (or dataset link)
* Outputs and visualisations
* Brief explanation of the experiment

## Technologies Used

* Python
* Jupyter Notebook / Google Colab
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## Objectives

* Learn fundamental AI and Machine Learning concepts.
* Implement ML algorithms using Python.
* Perform data preprocessing and visualisation.
* Build and evaluate predictive models.
